    {/* Section 1: Overview & Privacy Architecture */}
    <div class="space-y-4">
      <h2 class="text-2xl font-display font-extrabold text-white flex items-center gap-2">
        <span class="text-cyan-500 text-xl font-mono">01/</span> Local-First Privacy Architecture
      </h2>
      <p>
        Modern note-taking tools frequently route sensitive audio recordings, lecture notes, and ideas through cloud LLM APIs and third-party transcription endpoints. WhispNotes is engineered as a pure offline desktop application:
      </p>

      <div class="grid sm:grid-cols-2 gap-4 pt-2">
        <div class="bg-slate-950 border border-slate-850 rounded-xl p-5 space-y-2">
          <div class="font-mono text-xs text-cyan-400 font-bold">// ZERO BACKGROUND DAEMONS</div>
          <p class="text-xs text-slate-400 leading-relaxed font-sans">
            Unlike hybrid web wrappers that spawn local Node or Python HTTP servers on localhost ports, WhispNotes compiles directly to native Apple Silicon and Intel machine code with zero background HTTP listeners or external ports.
          </p>
        </div>

        <div class="bg-slate-950 border border-slate-850 rounded-xl p-5 space-y-2">
          <div class="font-mono text-xs text-blue-400 font-bold">// 100% LOCAL DATA RESIDENCY</div>
          <p class="text-xs text-slate-400 leading-relaxed font-sans">
            All notes, audio waveforms, speaker diarization metadata, and offline AI weights reside securely inside the local Application Support container with automatic JSON serialization and 30-day soft-delete trash retention.
          </p>
        </div>
      </div>
    </div>
