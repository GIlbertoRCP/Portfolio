    <div class="space-y-4">
      <h2 class="text-2xl font-display font-extrabold text-white flex items-center gap-2">
        <span class="text-cyan-500 text-xl font-mono">01/</span> What It Does
      </h2>
      <ul class="space-y-3.5">
        <li class="flex items-start gap-3"><span class="text-cyan-500 mt-1">✓</span><div><strong class="text-white">Record and transcribe.</strong> Whisper runs on-device and splits the transcript by speaker. Each line has a timestamp you can click to jump the audio there, and you can drop any line into your note as a quote.</div></li>
        <li class="flex items-start gap-3"><span class="text-cyan-500 mt-1">✓</span><div><strong class="text-white">Ask your notes.</strong> A local Gemma 3 model pulls out key points and action items, makes flashcards, and answers questions about the note you have open.</div></li>
        <li class="flex items-start gap-3"><span class="text-cyan-500 mt-1">✓</span><div><strong class="text-white">Write in Markdown.</strong> Live preview, tables, math, and wiki-style links with backlinks. A graph view shows how your notes link together.</div></li>
        <li class="flex items-start gap-3"><span class="text-cyan-500 mt-1">✓</span><div><strong class="text-white">Paste from anywhere.</strong> Pasting from a web page or a PDF turns HTML tables into Markdown tables and fixes broken bullet lists and run-together headings.</div></li>
        <li class="flex items-start gap-3"><span class="text-cyan-500 mt-1">✓</span><div><strong class="text-white">Open slides.</strong> PowerPoint and PDF decks open inside the app with their speaker notes, and you can link a note to a specific slide.</div></li>
      </ul>
    </div>

    {/* Section 3: How it's built */}
    <div class="space-y-4">
      <h2 class="text-2xl font-display font-extrabold text-white flex items-center gap-2">
        <span class="text-cyan-500 text-xl font-mono">03/</span> How It's Built
      </h2>
      <ul class="space-y-3.5">
        <li class="flex items-start gap-3"><span class="text-cyan-500 mt-1">✓</span><div><strong class="text-white">Native, not a web wrapper.</strong> It's Swift and SwiftUI, with AppKit where SwiftUI falls short. Many local-AI apps run a Python or Node server on a localhost port; this one doesn't open any ports.</div></li>
        <li class="flex items-start gap-3"><span class="text-cyan-500 mt-1">✓</span><div><strong class="text-white">Plain local storage.</strong> Notes, audio and transcripts are saved as JSON in the app's Application Support folder. Deleted notes stay in a trash for 30 days.</div></li>
        <li class="flex items-start gap-3"><span class="text-cyan-500 mt-1">✓</span><div><strong class="text-white">Organized as a Swift package.</strong> Models, services (storage, recording, Whisper, Gemma, smart paste), view models and views are separate, so each part can be tested on its own.</div></li>
        <li class="flex items-start gap-3"><span class="text-cyan-500 mt-1">✓</span><div><strong class="text-white">Shipped as a DMG.</strong> A build script packages the signed <code class="text-cyan-300">.app</code> and disk image. CI runs the test suite, and releases go out through GitHub Releases.</div></li>
      </ul>
    </div>
