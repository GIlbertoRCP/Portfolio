      <div class="grid sm:grid-cols-2 gap-4 pt-2">
        <div class="bg-slate-950 border border-slate-850 rounded-xl p-5 space-y-2">
          <h3 class="text-sm font-bold text-white">Keeping the motors responsive</h3>
          <p class="text-sm text-slate-400">ESP-NOW packets can arrive at any time. If handling them blocks the main loop, the motors stutter. Each packet is a fixed C struct that's the same on both ends, so it's parsed asynchronously and the motor loop never waits on the radio.</p>
        </div>
        <div class="bg-slate-950 border border-slate-850 rounded-xl p-5 space-y-2">
          <h3 class="text-sm font-bold text-white">Detecting a shaky hand</h3>
          <p class="text-sm text-slate-400">An MPU6050 on the claw samples acceleration on all three axes. When the moving standard deviation goes over a threshold, the claw is shaking, and the game takes time off the clock.</p>
        </div>
