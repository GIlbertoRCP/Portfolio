    <div class="space-y-4">
      <h2 class="text-2xl font-display font-extrabold text-white flex items-center gap-2">
        <span class="text-purple-500 text-xl font-mono">01/</span> System Overview &amp; Architecture
      </h2>
      <p>
        Movie Matcher resolves collaborative decision paralysis by allowing two or more users to join a synchronized session, swipe through curated movie decks, and discover mutual matches in real time. Rather than relying on static filters or heavy external cloud services, the platform combines a lightweight custom Two-Tower neural ranking pipeline with a responsive full-stack architecture:
      </p>

      <div class="grid sm:grid-cols-2 gap-4 pt-2">
        <div class="bg-slate-950 border border-slate-850 rounded-xl p-5 space-y-2">
          <div class="font-mono text-xs text-purple-400 font-bold">// CLIENT LAYER (REACT 19 + VITE)</div>
          <p class="text-xs text-slate-400 leading-relaxed font-sans">
            Built with React 19, Tailwind CSS v4, and Framer Motion physics. Movie cards respond to drag gestures with spring dynamics, rotation dampening, and velocity-based swipe commitment, complemented by Vaul drawer modals for movie details and Canvas Confetti celebration triggers.
          </p>
        </div>

        <div class="bg-slate-950 border border-slate-850 rounded-xl p-5 space-y-2">
          <div class="font-mono text-xs text-blue-400 font-bold">// BACKEND &amp; STORAGE (EXPRESS + SQLITE)</div>
          <p class="text-xs text-slate-400 leading-relaxed font-sans">
            Node.js/Express service with SQLite (<code class="text-blue-300">better-sqlite3</code>) for zero-latency relational persistence. Includes JWT auth, rate limiting, TMDB API proxying with memory caching (<code class="text-blue-300">node-cache</code>), and optional Authentik OIDC integration.
          </p>
        </div>
      </div>
    </div>

    {/* Section 2: Two-Tower Neural Recommendation Engine */}
    <div class="space-y-6">
      <h2 class="text-2xl font-display font-extrabold text-white flex items-center gap-2">
        <span class="text-purple-500 text-xl font-mono">02/</span> Two-Tower Neural Recommendation Pipeline
      </h2>
      <p>
        Implemented in <code class="text-purple-300">server/ml/twoTowerEngine.js</code>, the recommendation engine decouples candidate retrieval from deep nonlinear scoring:
      </p>

      {/* 64D Feature Vector */}
      <div class="space-y-3">
        <h3 class="text-base font-semibold text-white">1. 64-Dimensional Feature Representation</h3>
        <p>
          Each candidate title from TMDB is transformed into a compact 64-dimensional feature vector spanning four key feature domains:
        </p>
        
        <div class="bg-slate-950 border border-slate-850 rounded-xl p-4 font-mono text-xs space-y-2 text-slate-300">
          <div class="flex justify-between border-b border-slate-850 pb-1 text-slate-400">
            <span>INDEX RANGE</span>
            <span>FEATURE DOMAIN</span>
            <span>REPRESENTATION</span>
          </div>
          <div class="flex justify-between py-1">
            <span class="text-purple-400">00 .. 17</span>
            <span>18 TMDB Genres (Action, Sci-Fi, Horror, etc.)</span>
            <span class="text-slate-500">Multi-Hot Binary Flags</span>
          </div>
          <div class="flex justify-between py-1 border-t border-slate-900">
            <span class="text-purple-400">18 .. 21</span>
            <span>Rating, Vote Count Saturation, Popularity</span>
            <span class="text-slate-500">Continuous Normalized Scales</span>
          </div>
          <div class="flex justify-between py-1 border-t border-slate-900">
            <span class="text-purple-400">22 .. 27</span>
            <span>Release Decades (Pre-1980s through 2020s+)</span>
            <span class="text-slate-500">One-Hot Temporal Bins</span>
          </div>
          <div class="flex justify-between py-1 border-t border-slate-900">
            <span class="text-purple-400">28 .. 63</span>
            <span>Latent Content Representation</span>
            <span class="text-slate-500">Deterministic Seed Projection</span>
          </div>
        </div>
      </div>

      {/* Tower 1 & Tower 2 Breakdown */}
      <div class="grid sm:grid-cols-2 gap-4 pt-2">
        <div class="bg-slate-950 border border-slate-850 rounded-xl p-5 space-y-3">
          <div class="font-mono text-xs text-purple-400 font-bold">// TOWER 1: CANDIDATE RETRIEVAL</div>
          <p class="text-xs text-slate-400 leading-relaxed font-sans">
            Builds an active user preference vector dynamically from session history by accumulating positive feedback from liked titles (+1.5 weight) and dampening passed titles (-0.5 weight), followed by unit vector normalization. Candidate movies are rapidly filtered and ranked via cosine similarity against this active user vector.
          </p>
        </div>

        <div class="bg-slate-950 border border-slate-850 rounded-xl p-5 space-y-3">
          <div class="font-mono text-xs text-blue-400 font-bold">// TOWER 2: DEEP MLP RANKING</div>
          <p class="text-xs text-slate-400 leading-relaxed font-sans">
            Feeds retrieved candidates into a 3-layer deep Multi-Layer Perceptron (64 &rarr; 32 &rarr; 16 &rarr; 1) with ReLU activations on hidden units and a Sigmoid output neuron. The network scores cross-feature interactions and outputs an estimated like probability, calibrated to a 60%&ndash;99% match compatibility score.
          </p>
        </div>
      </div>

      {/* Feature Attribution */}
      <div class="bg-slate-950 border border-slate-850 rounded-xl p-5 space-y-2">
        <div class="font-mono text-xs text-emerald-400 font-bold">// EXPLAINABLE FEATURE ATTRIBUTION</div>
        <p class="text-xs text-slate-400 leading-relaxed font-sans">
          To provide user transparency, an attribution engine computes relative contributions for each recommendation—breaking down score weights across genre alignment (+35%), community critic rating (+28%), release era compatibility (+18%), and neural vector similarity (+19%).
        </p>
      </div>
    </div>

    {/* Section 3: Real-Time Session Synchronization */}
    <div class="space-y-4">
      <h2 class="text-2xl font-display font-extrabold text-white flex items-center gap-2">
        <span class="text-purple-500 text-xl font-mono">03/</span> Real-Time Session State Synchronization
      </h2>
      <p>
        The collaborative pairing workflow relies on Socket.IO rooms to synchronize user actions with sub-millisecond latency:
      </p>

      <div class="bg-[#0f1115] border border-slate-850 p-6 rounded-xl space-y-4">
        <div class="grid sm:grid-cols-3 gap-4 font-mono text-xs">
          <div class="bg-slate-950 p-4 border border-slate-850 rounded-lg space-y-2">
            <span class="text-purple-400 font-bold block">1. ROOM CREATION</span>
            <p class="text-slate-400 text-[11px] font-sans">
              Host generates a 6-character session code. The server registers a room instance in SQLite and joins the host's socket channel.
            </p>
          </div>

          <div class="bg-slate-950 p-4 border border-slate-850 rounded-lg space-y-2">
            <span class="text-blue-400 font-bold block">2. ASYNC SWIPING</span>
            <p class="text-slate-400 text-[11px] font-sans">
              Participants swipe independently. Every right-swipe emits a <code class="text-blue-300">swipe_movie</code> event, appending the movie ID to the player's like set in SQLite.
            </p>
          </div>

          <div class="bg-slate-950 p-4 border border-slate-850 rounded-lg space-y-2">
            <span class="text-emerald-400 font-bold block">3. INSTANT MATCH</span>
            <p class="text-slate-400 text-[11px] font-sans">
              When both participants mutually like the same movie, the server immediately broadcasts <code class="text-emerald-300">match_found</code>, triggering simultaneous confetti celebrations.
            </p>
          </div>
        </div>
      </div>
    </div>
